# TTS Voice Wizard

## Project Overview

This project demonstrates a Text-to-Speech (TTS) application built using Python. The application converts written text into spoken audio using the `pyttsx3` library. Users can customize the speech by selecting different system voices, adjusting the speech rate and volume, and saving the generated speech as an audio file.

## Features

- Converts text into speech
- Allows custom text input
- Supports multiple system voices
- Controls speech rate
- Controls speech volume
- Saves generated speech as an audio file

## Technologies Used

- Python
- pyttsx3
- pywin32

## Project Workflow

1. Install the required Python libraries.
2. Initialize the Text-to-Speech engine.
3. Provide text for conversion.
4. Convert the text into spoken audio.
5. Allow the user to enter custom text.
6. Display available system voices.
7. Configure voice, speech rate, and volume.
8. Generate and save the audio output.

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

    pip install -r requirements.txt

3. Open the Jupyter Notebook:

    jupyter notebook

4. Open `TTS_Voice_Wizard.ipynb`.
5. Run the notebook cells sequentially.

## Output

The application successfully converts written text into speech and can save the generated audio as an output file named `tts_output.mp3`.
